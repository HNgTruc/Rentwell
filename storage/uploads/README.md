# uploads/

Dữ liệu tải lên khi phát triển (thư mục dữ liệu của MinIO dev, tệp thử). Nội dung không vào git.

_Chưa có nội dung (sẽ làm ở giai đoạn tương ứng)._

## Quy tắc

- Chỉ `README.md` được theo dõi bởi git (xem `storage/.gitignore`).
- Compose dev gắn thư mục này làm volume của MinIO (cấu hình ở P0).

> Khi thêm hoặc xóa mục trong thư mục này, cập nhật bảng trên.
