# images/

Ảnh tĩnh của sản phẩm: ảnh minh họa, ảnh banner, ảnh mẫu cho seed.

_Chưa có nội dung (sẽ làm ở giai đoạn tương ứng)._

## Quy tắc

- Ưu tiên WebP hoặc AVIF; nén trước khi đưa vào.
- Tên chữ thường, không dấu, nối bằng gạch ngang (ví dụ `banner-trang-chu.webp`).

> Khi thêm hoặc xóa mục trong thư mục này, cập nhật bảng trên.
