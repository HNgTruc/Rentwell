# logo/

Logo và nhận diện thương hiệu Rentwell: bản chính, biểu tượng ứng dụng, favicon, các biến thể sáng/tối.

_Chưa có nội dung (sẽ làm ở giai đoạn tương ứng)._

## Quy tắc

- Ưu tiên SVG cho logo; kèm PNG khi cần.
- Logo do người dùng thiết kế; Claude không tự vẽ hay đổi (cổng thiết kế).

> Khi thêm hoặc xóa mục trong thư mục này, cập nhật bảng trên.
