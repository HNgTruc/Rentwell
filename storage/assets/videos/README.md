# videos/

Video ngắn dùng trong sản phẩm (giới thiệu, hướng dẫn).

_Chưa có nội dung (sẽ làm ở giai đoạn tương ứng)._

## Quy tắc

- Giữ nhẹ (dưới vài MB); video nặng để ngoài git hoặc Git LFS (cần duyệt).
- Kèm ảnh bìa (poster) trong `../images/` khi dùng trên web.

> Khi thêm hoặc xóa mục trong thư mục này, cập nhật bảng trên.
