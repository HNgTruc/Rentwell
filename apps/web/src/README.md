# src/

Mã nguồn.

## Bên trong

| Mục | Mô tả |
|---|---|
| `app/` | Route (trang, layout) của Next.js App Router; mỏng, chỉ ghép. |
| `components/` | Thành phần giao diện dùng chung riêng của app này. |
| `features/` | Theo tính năng nghiệp vụ; mỗi tính năng một thư mục (components, hooks, api). |
| `lib/` | Tiện ích và cấu hình phía client. |
| `styles/` | Kiểu dáng toàn cục. |

> Khi thêm hoặc xóa mục trong thư mục này, cập nhật bảng trên.
