# src/

Mã nguồn máy chủ MCP (dự kiến: `server.ts`, `apiClient.ts`, `auth.ts`, `audit.ts`).

## Bên trong

| Mục | Mô tả |
|---|---|
| `tools/` | Mỗi file một công cụ MCP (tồn kho, đơn trong ngày, chi tiết đơn, phiếu chuyển hàng, doanh thu, đánh giá mới). |

> Khi thêm hoặc xóa mục trong thư mục này, cập nhật bảng trên.
